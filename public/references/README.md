# Bundled IMGT/GENE-DB reference pack

`imgt-202632-7-swig-0.7.json.gz` is a modified, compact derivative of the
official [IMGT/GENE-DB reference sequences](https://www.imgt.org/download/GENE-DB/),
release `202632-7`, retrieved on `2026-08-08`.

Swig selects and reorganizes IG/TR V/D/J/C records, ungaps and normalizes
nucleotide sequences, derives compact coordinate metadata, selects one source
sequence per allele identifier, and joins selected coding IGH/TR constant
exons. Membrane-only and untranslated constant exons are omitted. IMGT,
Université de Montpellier, and CNRS do not endorse Swig or warrant this modified
pack.
