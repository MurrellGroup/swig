# KIMDB 1.1 reference sequences

This directory contains the `Macaca mulatta` and `Macaca fascicularis` IGH
V, D, and J FASTA exports obtained from KIMDB 1.1. They are bundled because
the publisher endpoint is HTTP-only and therefore cannot be fetched by an
HTTPS GitHub Pages application.

- Source: http://kimdb.gkhlab.se/
- Citation requested by the provider: Vázquez Bernat et al., *Immunity* (2021), PMID 33484642
- Retrieved for this static application: 2026-08-11

Swig validates and annotates these sequences in the browser at selection time;
the original FASTA records in this directory are retained without modification.
