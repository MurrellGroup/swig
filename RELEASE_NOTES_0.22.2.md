# Swig 0.22.2

This release converts the results area from a report-style landing page into a persistent application workspace.

- The large analysis-complete masthead and workflow stepper are no longer displayed above the results workspaces.
- Repertoire, Sequences, and Post-analysis use a high-contrast sticky application bar with a filled active state, explicit numbering, and preserved per-workspace scroll positions.
- Run statistics and technical settings now appear in a compact Run summary inside Repertoire rather than above every workspace.
- Every workspace rail includes Study design, Sample colors, output format, result download, Double-D evidence download where applicable, portable-session save, project checkpoint where applicable, and New analysis.
- Study metadata and sample colors open in bounded side drawers, keeping wide metadata tables out of the narrow rail without returning to report-style top panels.
- The Post-analysis introduction is reduced to a compact Overview note; the redundant large heading is removed.
- The results workspace uses more of the available viewport while retaining responsive horizontal rails on narrow screens.

Analysis behavior and file formats are unchanged.
